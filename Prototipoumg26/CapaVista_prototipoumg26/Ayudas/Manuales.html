Manuales del Sistema

En esta sección encontrará los manuales disponibles para el uso correcto del sistema. Cada manual describe paso a paso cómo realizar las operaciones principales.

Manual de Usuario

Explica cómo navegar por el sistema, iniciar sesión, gestionar registros y utilizar las funciones disponibles según el perfil asignado.

Manual de Administrador

Describe las tareas de configuración del sistema, gestión de usuarios, asignación de permisos y mantenimiento general.

¿Cómo usar los manuales?

Seleccione el manual que corresponda a su rol dentro del sistema. Lea cada sección en orden para familiarizarse con las funciones antes de utilizarlas.
